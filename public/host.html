Host a lobby

The host tool runs next to Overwatch. It builds the ranked code with everyone's rank tags, uploads your matches when they end and lists your lobby on Live.

Download the host tool Windows · latest release

Set up once

  1. Install itRun the installer. Windows warns about an unknown app because the installer isn't code-signed: click "More info", then "Run anyway". The tool updates itself after that.
  2. Get a host tokenAsk an admin on Discord. It's a password for your uploads: don't share it.
  3. Paste it in the toolSettings → Account, "Check and save". Then pick the region you host in under Settings → Game.
  4. Turn on the log fileIn Overwatch: Options → Gameplay → General → Enable Workshop Inspector Log File. Without it nothing is uploaded.

Every time you host

  1. Copy the ranked codeHome → Copy ranked code. The rank tags are as new as the code, so copy a fresh one each time.
  2. Import itCreate a new custom game, open Settings and paste the code with "Import / paste settings".
  3. PlayMatches upload when they end, and your lobby shows on Live while you play.

While you host

Going AFK
Turn on AFK on Home: your rating stays out of the rounds that start while it's on, and everyone else still counts.
Spectating or a crash
Moving to spectator or Overwatch closing mid-match is fine: the tool uploads what's in the log once it stops growing.
Waiting for an admin
Until an admin makes you a trusted host, your matches wait for a check before they count.

Tourney lobbies, the overlay and the upload list are in the full hosting guide.
